# Analyzer Jazyk

Modulární offline-first prostředí pro měření jazykových struktur.

Pracovní nástroje a dokumentace jsou ve složce [doma](doma/README.md). Ta slouží zatím jako rozcestník, protože hlavní index.html vznikne až po dokončení jednotlivých nástrojů.

Základní měření jsou pravidlová a nezávislá na generativní AI. Volitelné jazykové analyzátory lze připojit později.
