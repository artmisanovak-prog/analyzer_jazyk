# Lexikální a forenzní úhel

Lexikum: počet tokenů a unikátních slov, frekvenční distribuce, hapax legomena, délka slov, opakování kořenů a kumulativní slovní pestrost.

Forenzní měření: přesná repetice tokenu, fráze a n-gramu, vzdálenost mezi opakováními, návrat výrazu, přerušená konstrukce, výplňová slova.

Důležité: repetici lze definovat algoritmicky. Fixace nebo ztráta souseda jsou zatím výzkumné konstrukty a potřebují přesnou operacionalizaci, pozitivní i negativní příklady a verzi pravidla.
