# Syntaktický úhel

Měří stavbu vět a souvětí. Samotný výskyt spojky není důkazem syntaktické funkce.

Parametrické skupiny:
- větná segmentace: jednoduché věty, souvětí, hlavní a vedlejší věty;
- koordinace: souřadicí spojky a typy vztahů;
- subordinace: podřadicí spojky, druhy vedlejších vět a hloubka vnoření;
- větné členy: podmět, přísudek, předmět, přívlastek, příslovečné určení, doplněk;
- slovosled a pozice klitik;
- závislostní struktura: hloubka stromu a délka vazeb.

Stav: návrh parametrů. Plnohodnotné určování větných členů vyžaduje parser nebo samostatná pravidla. Později lze připojit UDPipe či Stanza jako volitelný adaptér. Základní nástroj na nich nebude záviset.
